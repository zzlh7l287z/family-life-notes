# 通宵9台紧急手术是怎样一种体验？这位医生的值班日记是很多医务人员真实写照

> 更新时间：2026-09-16 (UTC+8)

刚刚过去的五一小长假，医生们是怎么度过的？近日，Plus君在中山大学附属第一医院发现了普外科医生张赟建的工作日记。通宵经历9台紧急手术是怎样的体验？普外科医生们忙而不乱，妙手回春，在“死神”手中抢回生命的希望。

“那晚危急患者特别多，走路都得跑着去！”张赟建虽然辛苦，但更多的是“使命感”带来的自豪。他是4月30日早8点到5月1日早上8点的普外科二值医生，在这24小时里，中山一院值班医生们在通宵连续9台紧急手术中度过了“五一劳动节”。

**张赟建工作日记：**

我是4月30日的普外二值，今天从接班开始，值班手机总是响个不停。每当铃声响起时，我的脑海中的声音在告诉我，有一条生命在呼唤我，需要我去救助，容不得半点迟疑！

中午时间急诊几乎同时来了2名患者，一个是结肠癌术后肠梗阻患者，另一个是肝癌破裂出血。请我们会诊后，马上安排各项急诊检查，分别收入了胃肠外科和胆胰外科。

工作8年，张赟建记不清是第几次值班了。五一小长假是许多人期盼已久的假期，但是疾病不会放假，医院里的灯火，24小时为患者亮着。

这天是节日的第二天，但张赟建“不是一个人在战斗”。当天普外科的每个病区都有2-3个一值医生，还有1名住院总医师、2名二值医生和1名教授或主任级的三值医生。同时，还有血管外科、胃肠外科、麻醉科、内科等多个学科的值班医生，他们都坚守在岗位，做公众的“健康守门人”。

“医院的体系完善，值班的后备力量也很强大，能够及时应对随时可能到来的突发情况。”张赟建说。

急诊送来的肠梗阻患者，手术探查指征明确，张赟建和同事马上安排了急诊手术。然而就在术中，急诊和胆胰外科多次来电需要外科支援，当天值班的另外一个普外二值医生，立即赶去协助。

在“来电求援”的胆胰外科，此时有2名危重患者。肝癌破裂出血导致血色素持续下降的患者转入了SICU，还有一名高龄患者，考虑胆道感染引起的突发感染性休克，也经抢救后转入SICU。

刚下手术台，张赟建还没来得及喝口水，值班手机又响起来了。

**张赟建工作日记：**

就在这个时候，急诊又来了2名患者需要外科协助诊治。一个是考虑腹主动脉瘤破裂，失血性休克患者。我们马上开通绿色通道，联系了血管外科二值和三值，在很短时间内做完术前准备，送入手术室抢救。另一个患者考虑阑尾炎。

张赟建是腹主动脉瘤患者的首诊普外医生，这个疾病起病急、危害大、病程短。腹主动脉瘤是一种动脉扩张性疾病，就像高压血流在血管中形成的一个大气球，这个“大血囊”本身是一种良性疾病，但是到了一定程度就成了致命的杀手。特别是腹主动脉瘤破裂出现的失血性休克，抢救可谓是“争分夺秒”。

当血管外科正在抢救主动脉瘤破裂患者时，妇科有一例术后大出血的患者，需要在手术台上会诊协助止血抢救。

“危急患者一个接一个，时间就是生命！”张赟建再次赶往手术室，和血管外科三值医生一起上手术台找到出血的动脉，做了缝扎处理后，再一次把大出血的妇科患者从死亡线上拉了回来。

值班电话此时再次响了起来。

**张赟建工作日记：**

正当阑尾炎患者要准备送手术室的时候，外科住院总医师接到了一个电话，胃肠外科有一名术后患者出现休克症状，不排除术后肠瘘引起，需要马上急诊手术抢救。于是阑尾手术暂缓，先处理更紧急的病人。

“这个时候，最希望得到患者和家属的理解。”张赟建说，在急诊，每个患者都可能有生命危险。在有限的医疗资源下，医生需要分疾病发病的轻重缓急进行救治，比如和休克的患者相比，阑尾的患者的手术可能需要等待。

中山一院作为华南地区的“医疗龙头”，送医的急危重症患者更多。这一晚，他们接收的患者中至少有7个患者都是生命垂危的重症患者，和张赟建一样奋斗了一整夜的医务人员们，在忙碌中迎来了五一劳动节。

**张赟建工作日记：**

不知不觉已到了五月一日的清晨7点，在几间不同的手术室进进出出的时候，还看到了其他好几个房间也在进行手术。一问主班护士得知，原来昨晚至今天凌晨总共做了9台急诊大手术，包括有3台移植，2台胃肠大手术，1台主动脉瘤破裂出血，1台妇科术后大出血，1台产科急诊，1台食道异物。阑尾炎还在等待。

5月1日中午，阑尾炎患者终于上了手术台。“听同事说，这个阑尾手术患者合并了其他疾病，病情复杂，出血风险大。”张赟健说，还好病人和家属都十分理解，经过沟通充分知情后，阑尾患者也顺利完成了手术。

张赟建医生的经历，是千千万万个外科医生工作的缩影。五一劳动节对于大部分人而言，是个值得庆祝和休息的日子，但对于值班的医护人员而言，这是平常工作的一天。在感谢敬业与奉献的外科医生的同时，Plus君不禁希望，医务人员能少一些劳累，多一些喜悦；社会对医生能少一些误解，多一份体谅和温暖。

“虽然比较辛苦，但是能救回一条生命，觉得再多的付出都是值得的。”张赟建说，每当救回一个人，医生这个职业带来的自豪感油然而生。特别是看到病人康复，听到患者和家属的感谢时，“这是我当医生最满足的时刻。”
